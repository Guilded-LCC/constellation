# Changelog

All notable changes to this project are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses
[Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-10-21

First public release.

- Team chat with servers, channels, roles, DMs, threads and attachments.
- Moderation tools and audit logs.
- Supabase backend with row-level security migrations.
- Plain JavaScript front end with self-hosting instructions.
- MIT license, security policy and contributing guide.
